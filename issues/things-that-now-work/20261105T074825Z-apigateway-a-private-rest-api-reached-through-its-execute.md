The execute-api data plane is not spelled by the control-plane model, so for it: recorded behavior only — once the interface endpoint is available, the NLB targets are healthy and the VpcLink is AVAILABLE, a GET on the front API's stage URL is proxied through the VPC link to the private API's stage and returns the private method's own answer: HTTP 200 with the MOCK integration response template body (a single JSON object carrying the run's nonce) while the private API's /policy allows execute-api:Invoke with Condition StringEquals aws:SourceVpce equal to that endpoint id. Not the control-plane handlers: PutIntegration, UpdateRestApi(/policy) and CreateDeployment were all accepted here.
