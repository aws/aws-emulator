# ListAWSDefaultServiceQuotas omits most default quotas for access-analyzer, acm, acm-pca and seven more service codes

> _Note: this issue was identified against the code base at commit `e635fc8db7925c597029a243d97ecda6419e6d1a`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
ListAWSDefaultServiceQuotas

## Description
The emulator's Service Quotas default-quota catalog is a hand-seeded stub. ListAWSDefaultServiceQuotas answers 200 for every ServiceCode but returns only a handful of entries (and in some cases entries AWS never serves), instead of the service's full default-quota set. This issue bundles TEN net-new causes, one per ServiceCode whose default catalog diverges. All ten share one root cause family: the seeded catalog table, not the operation's wire framing.

Smithy: ListAWSDefaultServiceQuotas -> ListAWSDefaultServiceQuotasResponse { Quotas: list<ServiceQuota>, NextToken }. ServiceQuota members ServiceCode, ServiceName, QuotaArn, QuotaCode, QuotaName, Value, Unit, Adjustable, GlobalQuota, Period, UsageMetric. The model does not enumerate quota codes, so the catalog CONTENT is recorded behavior only; the recordings are the requirement. In all ten causes both AWS and the emulator answer HTTP 200, so the divergence is purely in the response body.

General shape of the fault, visible across the ten causes: (a) real AWS quota codes have the form L-XXXXXXXX (eight hex digits) and the emulator omits nearly all of them; (b) where the emulator does seed an entry it sometimes uses an invented camel-case QuotaCode (for example AnalyzersPerRegion, ACMCertificates, ImportedCertificates, CertificateAuthorities, AppsPerRegion, BranchesPerApp) that AWS does not return at all, so the entry is both extra and wrong; (c) each returned ServiceQuota must carry the per-quota Description, Unit, Adjustable, GlobalQuota, Value, QuotaArn of the form arn:aws:servicequotas:<region>::<serviceCode>/<quotaCode>, and the optional Period/UsageMetric blocks where the recorded quota has them.

Cause 1 of 10 - ServiceCode access-analyzer.
AWS: returns the full Access Analyzer default set, including L-4599575C (Concurrent policy generations, Adjustable false, Unit None), L-6F85FE0C (Organization level analyzer, Adjustable true), L-94099EDD (Policy generation CloudTrail data size, Unit Gigabytes), L-8750DAE0 (Access previews per analyzer per hour), L-2F63646F (account level analyzers per analyzer type) and L-FD4CD927, each with ServiceName 'Access Analyzer' and a QuotaArn under arn:aws:servicequotas:<region>::access-analyzer/<quotaCode>.
Emulator: those quota codes are absent from Quotas, and an invented entry QuotaCode 'AnalyzersPerRegion' is present instead.
Why: a client enumerating the account's default analyzer limits sees no L- code it can pass to GetAWSDefaultServiceQuota / RequestServiceQuotaIncrease, and sees a code AWS would reject.
Fix: the service-quotas default-quota catalog seed (the data table the ListAWSDefaultServiceQuotas handler reads), not the serializer.
Traces: service-quotas-catalog-list-aws-default-service-quotas-access-analyzer#task#1.

Cause 2 of 10 - ServiceCode acm.
AWS: returns the ACM default set with ServiceName 'AWS Certificate Manager (ACM)', including the per-API rate quotas L-8849A1A8 (Rate of UpdateAcmeEndpoint API requests), L-A7230D7D (Rate of CreateAcmeEndpoint API requests), L-535A8003 (Rate of DescribeAcmeExternalAccountBinding API requests) and roughly forty further L- codes, each carrying Period {PeriodUnit SECOND, PeriodValue 1} and a UsageMetric block (MetricNamespace AWS/Usage, MetricName CallCount, MetricStatisticRecommendation Sum, MetricDimensions Service/Resource/Type/Class).
Emulator: all of those are missing; the seeded entries use invented codes ACMCertificates and ImportedCertificates.
Why: throttle-rate and certificate-count quotas are invisible, and the Period/UsageMetric blocks a quota-dashboard client reads are never emitted.
Fix: the service-quotas default-quota catalog seed.
Traces: service-quotas-catalog-list-aws-default-service-quotas-acm#task#1.

Cause 3 of 10 - ServiceCode acm-pca.
AWS: returns the AWS Private Certificate Authority default set (ServiceName 'AWS Private Certificate Authority'), including L-506CC328 (Rate of PutPolicy requests, Value 5), L-4065FDCB (Rate of DeleteCertificateAuthority requests, Value 10), L-773738D3 (Rate of CreatePermission requests, Value 1), L-5A3CF806 (Rate of ListCertificateAuthorities requests, Value 20) and about twenty further L- codes.
Emulator: those are absent; an invented CertificateAuthorities entry is served instead.
Why: the whole private-CA request-rate catalog is unreadable.
Fix: the service-quotas default-quota catalog seed.
Traces: service-quotas-catalog-list-aws-default-service-quotas-acm-pca#task#1.

Cause 4 of 10 - ServiceCode aco-automation.
AWS: returns the AWS Compute Optimizer Automation default set (ServiceName 'AWS Compute Optimizer Automation'), including L-D0AFC926 (Throttle rate limit for ListAutomationEvents), L-E33DC3FB (ListRecommendedActions), L-D5E7759E (UntagResource), L-D0368739 (GetAutomationEvent) and about twenty further throttle-rate L- codes, all Adjustable false, Unit None.
Emulator: no entry for any of them.
Why: the service appears to have no default quotas at all.
Fix: the service-quotas default-quota catalog seed.
