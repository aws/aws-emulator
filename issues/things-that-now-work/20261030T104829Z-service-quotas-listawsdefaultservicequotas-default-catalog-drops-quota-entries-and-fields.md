## Description
This bundle carries FIVE net-new causes, one per ServiceCode. They share one component — the static default-quota catalog that ListAWSDefaultServiceQuotas serves — but each ServiceCode's data is separate and all five must be corrected and re-replayed before this issue is closed. Every step answered 200 as expected; only the Quotas payload diverges.

Shared model grounding (Smithy, com.amazonaws.servicequotas): ListAWSDefaultServiceQuotas(ServiceCode required) returns Quotas as a list of ServiceQuota, whose members are ServiceCode, ServiceName, QuotaArn, QuotaCode, QuotaName, Value, Unit, Adjustable (boolean, default false), GlobalQuota, UsageMetric (MetricInfo with MetricNamespace, MetricName, MetricDimensions, MetricStatisticRecommendation), Period (QuotaPeriod with PeriodValue, PeriodUnit) and Description (@length 0..350). The model does not enumerate per-service defaults, so the authority for which entries exist and what they contain is the recorded AWS response for that ServiceCode — recorded behavior only.

Cause 1 of 5: ServiceCode config.
AWS: L-0BE82991 is the 'AWS Config Rules per region' quota, non-adjustable, and carries a Description.
Emulator: the entry is named 'Config rules per Region', reports Adjustable true, and has no Description.
Why: Adjustable true points a client at RequestServiceQuotaIncrease for a quota AWS will not raise, and the renamed quota is not found by callers matching on QuotaName.
Fix: the default-quota catalog data for ServiceCode config in the service-quotas crate (the seed table ListAWSDefaultServiceQuotas reads).
Traces: service-quotas-catalog-list-aws-default-service-quotas-config#task#1.

Cause 2 of 5: ServiceCode kinesis.
AWS: L-0918CF54 (shards per Region) carries a Description.
Emulator: the entry is present with the right name and value but Description is absent.
Why: Description is a modeled member; clients that render quota catalogs show an empty explanation.
Fix: add Description to the default-quota catalog data for ServiceCode kinesis.
Traces: service-quotas-catalog-list-aws-default-service-quotas-kinesis#task#1.

Cause 3 of 5: ServiceCode monitoring.
AWS: the CloudWatch default catalog contains the full set of API-rate and resource quotas, each a complete ServiceQuota with Description, QuotaArn, Adjustable, Value and — for rate quotas — Period and UsageMetric (e.g. L-722EAE58 ANOMALY_DETECTION_BAND usage rate, L-69C44FFD rate of ListDashboards requests with Period SECOND/1, L-6300B446 rate of DescribeAnomalyDetectors requests).
