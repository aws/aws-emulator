# service-quotas default-quota catalog misbinds QuotaCodes and omits Descriptions for events fms fsx gamelift glue imagebuilder

> _Note: this issue was identified against the code base at commit `63a5892813ef10d964868e55c8a5b01f4a53fc31`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
ListAWSDefaultServiceQuotas

## Description
Shared fault: the emulator's ListAWSDefaultServiceQuotas default-quota catalog pairs a QuotaCode with the WRONG quota's metadata and leaves Description unpopulated on rows that have one. For six ServiceCodes the emulator answers HTTP 200 (the recording is also 200, so nothing is wrong with the status or the envelope) but the Quotas list it serves either (a) binds a recorded QuotaCode to a different quota's QuotaName/Description/Value/Unit/Adjustable/Period/UsageMetric/QuotaContext, (b) omits Description entirely on a row AWS documents, or (c) re-words a Description that AWS publishes verbatim. This issue bundles SIX causes, one per ServiceCode: events, fms, fsx, gamelift, glue, imagebuilder. All six must be fixed and re-replayed before it is closed.

General AWS grounding (applies to every cause). Smithy (services/service-com-amazonaws-servicequotas-servicequotasv20190624/smithy-model/com-amazonaws-servicequotas-servicequotasv20190624.json): ListAWSDefaultServiceQuotas(ServiceCode required, length 1..63, pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$; NextToken; MaxResults 1..100) -> ListAWSDefaultServiceQuotasResponse{Quotas: ServiceQuotaListDefinition, NextToken}, paginated(items=Quotas); errors AccessDeniedException 403, IllegalArgumentException 400, InvalidPaginationTokenException 400, NoSuchResourceException 404, TooManyRequestsException 429, ServiceException 500.
