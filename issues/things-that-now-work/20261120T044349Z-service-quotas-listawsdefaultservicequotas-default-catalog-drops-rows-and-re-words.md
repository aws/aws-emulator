# ListAWSDefaultServiceQuotas default catalog drops rows and re-words/understates fields for ram rds redshift route53resolver s3 scheduler secretsmanager

> _Note: this issue was identified against the code base at commit `d9aa09bf364269536af7912cc398b8c726b9e0b1`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
ListAWSDefaultServiceQuotas

## Description
ListAWSDefaultServiceQuotas returns 200 for each of these ServiceCodes, but the emulator's seeded default-quota catalog is not AWS's: for seven more service codes it omits AWS's L-coded default rows outright, and for the rows it does serve it re-words QuotaName/Description or serves a Value that is not the AWS default. This is the same class of catalog-fidelity defect already filed for other service codes (see open issues 20261113T222805Z-service-quotas-access-analyzer-acm-acm-pca-and-6-more.md, 20261118T044910Z-service-quotas-default-quota-catalog-rows-misbound-across-sns-sqs.md, 20261119T100022Z-service-quotas-dynamodb-ebs-ecr-and-6-more-listawsdefaultservicequotas-catalogs.md); none of those covers these seven codes, and the replay reports no owner for them. SEVEN CAUSES, one per ServiceCode. The general requirement for every cause: for a ServiceCode AWS publishes, the response's Quotas list MUST contain one ServiceQuota per AWS default quota for that code, keyed by its AWS QuotaCode, each carrying the AWS QuotaName, Description, Value, Unit, Adjustable, GlobalQuota, QuotaArn (arn:aws:servicequotas:<region>::<ServiceCode>/<QuotaCode>) and, where AWS defines them, Period and UsageMetric. Region in the ARN and the row set are the only environment-dependent parts; the quota codes, names, descriptions, units and default values are AWS data, not per-run values.

Cause 1 of 7 — ram (fixture service-quotas-catalog-list-aws-default-service-quotas-ram, step task#1).
AWS: Smithy model com-amazonaws-servicequotas-servicequotasv20190624, ListAWSDefaultServiceQuotas -> ListAWSDefaultServiceQuotasResponse.Quotas: list<ServiceQuota>; ServiceQuota.Value is a QuotaValue double (range 0..10000000000) carrying the AWS default quota value. Recorded behavior: for ServiceCode "ram" the row QuotaCode L-9EBA15DD has Value 1500.0.
Emulator: serves that row with Value 100.0.
Why: a client that reads the account's default RAM quota to size a share plan or to decide whether to request an increase computes a limit 15x smaller than AWS's and will refuse or throttle work AWS would allow.
Fix: the seeded default-quota catalog data behind the ListAWSDefaultServiceQuotas handler for ServiceCode ram (the row's Value field).
Traces: service-quotas-catalog-list-aws-default-service-quotas-ram#task#1.
