# Security Hub control summaries and the catalog domain/objective taxonomy are emulator-invented

> _Note: this issue was identified against the code base at commit `1cef0270414d463e8e4cd5e638402f2f0968b2f1`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
ListControls

## Description
The same seeded-catalog defect on the Security Hub side of ListControls and on the catalog taxonomy read by ListDomains and ListObjectives: all three operations answer the modeled 200, but their @required lists hold emulator-authored records instead of the AWS-published ones. FIVE divergence clusters are bundled here, numbered as causes below; ALL FIVE must be closed and re-replayed before this issue is done.
