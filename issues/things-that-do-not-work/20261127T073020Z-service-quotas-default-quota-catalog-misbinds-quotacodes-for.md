# service-quotas default-quota catalog misbinds QuotaCodes for dynamodb ebs ecr elasticache efs elb rds redshift route53resolver s3

> _Note: this issue was identified against the code base at commit `33932bf6f81e8cc72c4071b6c64638fb9bd78d71`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
ListAWSDefaultServiceQuotas

## Description
Shared fault: the emulator's ListAWSDefaultServiceQuotas default-quota catalog pairs a QuotaCode with the WRONG quota's metadata, omits rows AWS publishes, drops Description on rows that have one, and re-words Descriptions AWS publishes verbatim. The status and envelope are correct everywhere (recorded 200, served 200); only the Quotas list body diverges. This issue bundles TEN causes, one per ServiceCode: dynamodb, ebs, ecr, elasticache, elasticfilesystem, elasticloadbalancing, rds, redshift, route53resolver, s3. All ten must be fixed and re-replayed before it is closed.

General AWS grounding (applies to every cause). Smithy (services/service-com-amazonaws-servicequotas-servicequotasv20190624/smithy-model/com-amazonaws-servicequotas-servicequotasv20190624.json): ListAWSDefaultServiceQuotas(ServiceCode required, @length 1..63, @pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$; NextToken @length 0..2048; MaxResults @range 1..100) -> ListAWSDefaultServiceQuotasResponse{Quotas: ServiceQuotaListDefinition, NextToken}, @paginated(items=Quotas); errors AccessDeniedException 403, IllegalArgumentException 400, InvalidPaginationTokenException 400, NoSuchResourceException 404, TooManyRequestsException 429, ServiceException 500. Smithy ServiceQuota members: ServiceCode, ServiceName, QuotaArn, QuotaCode (@pattern ^[a-zA-Z][a-zA-Z0-9-]{1,128}$), QuotaName, Value (QuotaValue double @range 0..10000000000), Unit, Adjustable (boolean, default false), GlobalQuota (boolean, default false), UsageMetric (MetricInfo), Period (QuotaPeriod), QuotaContext (QuotaContextInfo), Description (QuotaDescription @length 0..350). The model fixes the SHAPE but says nothing about the catalog's contents, so the per-quota contents are recorded behavior only: AWS returns, for a given ServiceCode, its published default-quota set in which every QuotaCode carries ITS OWN QuotaName, Description, Value, Unit, Adjustable, Period, UsageMetric and QuotaContext. The requirement is the QuotaCode -> metadata pairing, the presence of each row AWS publishes, and the presence and exact wording of each row's Description. The individual numbers below are quoted only as the recording's examples of a mispairing, never as the requirement themselves. No error path is involved: every cause is a 200-vs-200 body divergence, so there is no status, error code or error message to reproduce here.
