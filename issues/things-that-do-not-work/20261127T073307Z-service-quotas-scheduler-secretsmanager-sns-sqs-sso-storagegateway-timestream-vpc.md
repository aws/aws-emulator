## Operation
ListAWSDefaultServiceQuotas

## Description
Shared fault: the emulator's ListAWSDefaultServiceQuotas default-quota catalog pairs a QuotaCode with the WRONG quota's metadata, omits rows AWS publishes, drops Description on rows that have one, and re-words Descriptions AWS publishes verbatim. The status and envelope are correct everywhere (recorded 200, served 200); only the Quotas list body diverges. This issue bundles TEN causes, one per ServiceCode: scheduler, secretsmanager, sns, sqs, sso, storagegateway, timestream, vpc, vpc-lattice, wafv2. All ten must be fixed and re-replayed before it is closed.
